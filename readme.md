### Команди:

- `npm start` &mdash; старт сервера в режиме production
- `npm run start:dev` &mdash; старт сервера в режиме розроботки (development)
- `npm run lint` &mdash; запустить выполнение проверки кода с eslint, необходимо выполнить перед каждым PR и исправить все ошибки линтера
- `npm lint:fix` &mdash; та же проверка линтера, но с автоматическим исправлением простых ошибок
